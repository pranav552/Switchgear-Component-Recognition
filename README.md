\# Switchgear Component Recognition using Computer Vision



\## Project Overview



This project focuses on automatic detection and recognition of switchgear components using Computer Vision and YOLO object detection models.



The objective is to identify switchgear components from images and compare the performance of YOLOv8 and YOLO11 models.



\---



\## Project Objective



\- Detect switchgear components automatically.

\- Compare YOLOv8 and YOLO11 performance.

\- Evaluate object detection accuracy.

\- Deploy the trained model.



\---



\## Technologies Used



\- Python

\- Google Colab

\- YOLOv8

\- YOLO11

\- OpenCV

\- Roboflow

\- Ultralytics

\- Computer Vision



\---



\## Dataset



\- Total Classes: 22

\- Images collected and annotated using Roboflow.

\- Dataset split into Train, Validation and Test sets.



\---



\## Model Performance



| Model | Precision | Recall | mAP@50 | mAP@50-95 |

|--------|----------:|--------:|--------:|-----------:|

| YOLOv8 | 95.2% | 90.2% | 95.8% | 82.0% |

| YOLO11 | 95.7% | 91.6% | 96.1% | 82.6% |
